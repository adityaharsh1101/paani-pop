# PAANI POP — Quick Start

## What you received

This bundle contains the PAANI POP web application, Firebase backend foundation, operating documents, pilot-readiness worksheets and the first 30 days of Instagram and LinkedIn content.

## Explore without configuring a cloud project

1. Install Node.js 22.12+ on a personal development environment, or use a hosted development workspace.
2. In the project folder, run `npm install` and `npm run dev`.
3. The app opens in Demo mode if Firebase configuration is absent. Demo records are stored only in that browser and are not shared.

## Make it a shared SaaS

Read `README.md` and `docs/DEPLOYMENT_AND_SECURITY.md`. A Firebase project, enabled Authentication/Firestore/Storage, App Check, Functions secrets, domain, privacy/terms pages and a deployment are required. Keep development and production Firebase projects separate.

Do not invite outside advertisers, venues or suppliers into the PAANI POP operations workspace. Cross-organisation record sharing and partner-scoped portals are not included yet. Give each organisation its own workspace until that feature is implemented and security-reviewed.

## Launch communications

Use `marketing/CONTENT_CALENDAR.md` as the schedule, `marketing/INSTAGRAM_30_DAYS.md` and `marketing/LINKEDIN_30_DAYS.md` as the copy library, and `marketing/INSTAGRAM_PRODUCTION_SCRIPTS.md` to produce the visuals and short videos. Adapt dates and details before publishing.

## Stage and claims

The copy assumes PAANI POP is at concept/pilot-planning stage. Mark all mock pack visuals as concept artwork. Never claim approvals, certifications, partners, customers, distribution, sales or performance results until independently verified.
